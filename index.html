How DJ Crate currently finds tracks — and what it can't do yet

The server identifies public SoundCloud references when accessible, then searches Apple's public music catalogue in multiple markets using the reference artist/title and chosen subgenre. It deduplicates results, excludes exact references, scores available metadata, and can enforce a minimum relevance threshold. It does not have cross-platform full-catalogue search, track-level popularity data, licensed audio embeddings, verified BPM/key, or direct playlist creation in SoundCloud/Spotify. The 90%/75% settings express product priorities, not measured model accuracy. True strict sound matching requires licensed audio features or a permissioned catalogue.
