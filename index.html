How DJ Crate currently finds tracks — and what it can't do yet

The server identifies public SoundCloud references when accessible, searches Apple's public music catalogue, and — when approved API credentials are configured — separately searches SoundCloud public uploads using the same reference and genre fields. It deduplicates results, excludes exact references, scores available metadata, and can enforce a minimum relevance threshold. It does not have cross-platform full-catalogue search, licensed audio embeddings, verified BPM/key, or direct playlist creation in SoundCloud/Spotify. The sliders adjust ranking preferences. Popularity uses SoundCloud play counts when available. True strict sound matching requires licensed audio features or a permissioned catalogue.
